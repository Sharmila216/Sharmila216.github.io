Lab 01 · UI Design

Building the Home Screen with Jetpack Compose

Laid out StudyMate's first screen in Jetpack Compose — learning composable functions, column/row layouts, and Material Design principles from scratch. A complete mindshift from XML-based UI.

Reflection

Lab 1 was my first real encounter with Compose's declarative UI style. I learned to build layouts using composable functions and apply Material Design principles cleanly. The foundation built here echoed through every screen I designed afterwards.

Lab 02 · Interaction

User Interaction & State Management

Wired up the behaviour behind the UI — click events, text input handling, and Compose state management using remember and mutableStateOf. Watching UI re-render live as state changed was genuinely satisfying.

Reflection

This lab made state management finally click for me. I practised button taps, text inputs, and conditional displays with confidence. Reactive UI thinking became second nature from here onward.

Lab 03 · Material Design

Theming with Material Design 3

Defined StudyMate's colour, typography, and shape tokens using Material Design 3. Explored how editing a single theme file changes the entire app's visual identity — a true design system experience.

Reflection

Lab 3 unlocked my eye for design — learning M3's token system showed me how professional apps maintain visual consistency. This directly shaped StudyMate's polished look and feel.

Lab 04 · Navigation

Bottom Nav & Multi-Screen Flow

Connected screens with Navigation Compose and a bottom navigation bar, passing arguments between destinations and managing the back stack gracefully. My app finally felt like a real product.

Reflection

Navigation Compose transformed my single-screen experiments into a real multi-screen app. Planning the navigation graph before writing composables saves hours of rework — a lesson I carried into both projects.

Lab 05 · Room Database

Saving Data with Room Persistence

Added a Room database to persist user data across app restarts — mastering Entities, DAOs, and ViewModel-connected Flows. Seeing data survive a restart was the moment the app felt like a real product.

Reflection

Room was the toughest lab and also my favourite. Local persistence turned my app from a toy into something that actually remembers its users. This became the heartbeat of StudyMate's data layer.

Personal Growth

Reflection & Learning Journey

Looking back at everything built — from the first composable in Lab 1 to the full cloud-connected app in Project 2.

🏗️
Project 01
StudyMate — Core Navigation App
Kotlin Jetpack Compose Navigation Material Design 3

What I built: A structured multi-screen Android app where students can manage tasks, track exam schedules, and navigate study content — all in one clean interface. This project combined everything from Labs 1 to 4.

💡 Key Achievement
Architected a full navigation graph with 5+ screens, argument passing between destinations, and a polished Material Design 3 theme — all from scratch.
🚀
Project 02
StudyMate — Full Learning Platform
Room DB Firebase Dictionary API Sensors SDG 4

What I built: A full-featured learning platform with offline-first Room persistence, Firebase cloud sync for Study Tips community, a Free Dictionary API screen, and live device sensors — aligned with SDG 4: Quality Education.

💡 Key Achievement
Designed a hybrid data architecture where Room handles personal data offline and Firebase syncs community content in real-time — both coexisting gracefully in one app.

When I started Lab 1, I honestly did not know what a composable function was — now I can architect a multi-screen Android app with local persistence, cloud sync, REST APIs, and live device sensors. That transformation did not happen overnight; it happened one frustrating bug at a time, one late-night debugging session at a time, and one "aha!" moment at a time. Every lab in this course was a carefully placed stepping stone, and looking back, I can see exactly how each one built on the last.

The most profound realisation was how deeply interconnected everything became — the UI instincts from Lab 1, the state management discipline from Lab 2, the design sensibility from Lab 3, the navigation architecture from Lab 4, and the persistence mastery from Lab 5 all wove together inside StudyMate. Building an app that genuinely helps students study better, powered by technology I built myself, is the most meaningful thing I have created in my academic journey so far. SDG 4 is not just a label on my portfolio — it is the reason I chose every single feature I built.
