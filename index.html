Academic Work

Lab Exercises

Lab 01

UI Design with Jetpack Compose

Building the foundation of Android UI using composable functions, layouts, and theming in Jetpack Compose.

Lab 1 was my first real encounter with Jetpack Compose's declarative UI style — a complete mindshift from XML. I learned to build layouts using composable functions and apply Material Design principles cleanly. The foundation built here echoed through every screen I designed afterwards.

Lab 02

User Interaction & State Management

Implementing click events, user input handling, and Compose state management using remember and mutableStateOf.

This lab made state management finally click for me — watching UI re-render live as state changed was genuinely satisfying. I practised button taps, text inputs, and conditional displays with confidence. Reactive UI thinking became second nature from here onward.

Lab 03

Material Design 3 Theming

Applying Material Design 3 components, colour schemes, typography, and dynamic theming in a Compose application.

Lab 3 unlocked my eye for design — learning M3's token system showed me how professional apps maintain visual consistency. I explored colour harmonies, shape systems, and adaptive layouts across screen sizes. This directly shaped StudyMate's polished look and feel.

Lab 04

Navigation & Multi-Screen Apps

Implementing Jetpack Navigation Compose to build multi-screen applications with back stack management and argument passing.

Navigation Compose was the lab that transformed my single-screen experiments into a real multi-screen app. Defining navigation graphs, passing arguments between destinations, and gracefully managing the back stack felt like assembling a puzzle. My apps finally felt production-ready after this.

Lab 05

Room Database & Local Persistence

Integrating Room database to store, retrieve, update, and delete data locally with DAO patterns and Flow.

Room was the toughest lab and also my favourite — mastering Entities, DAOs, and ViewModel-connected Flows felt like levelling up as a developer. Local persistence turned my app from a toy into something that actually remembers its users. This became the heartbeat of StudyMate's data layer.

Personal Growth

Reflection & Learning Journey

When I started Lab 1, I honestly did not know what a composable function was — now I can architect a multi-screen Android app with local persistence, cloud sync, REST APIs, and live device sensors. That transformation did not happen overnight; it happened one frustrating bug at a time, one late-night debugging session at a time, and one "aha!" moment at a time. Every lab in this course was a carefully placed stepping stone, and looking back, I can see exactly how each one built on the last.

The most profound realisation was how deeply interconnected everything became — the UI instincts from Lab 1, the state management discipline from Lab 2, the design sensibility from Lab 3, the navigation architecture from Lab 4, and the persistence mastery from Lab 5 all wove together inside StudyMate. Building an app that genuinely helps students study better, powered by technology I built myself, is the most meaningful thing I have created in my academic journey so far. SDG 4 is not just a label on my portfolio — it is the reason I chose every feature I built.
